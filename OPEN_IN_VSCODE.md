# Открыть TableFlow в VS Code

1. Установите Git, VS Code и Node.js 24 LTS.
2. В VS Code нажмите Ctrl+Shift+P, выберите Git: Clone и укажите:
   https://github.com/sakenovbeksultan51-crypto/tableflow-ai.git
3. Войдите в GitHub, если потребуется: репозиторий приватный.
4. Выберите папку и нажмите Open.
5. В меню Terminal → New Terminal выполните по очереди:

```sh
npm ci
npm run build
npx wrangler d1 execute DB --local --config dist/server/wrangler.json --file drizzle/0000_superb_lady_ursula.sql
npm start
```

Откройте адрес, указанный в терминале, обычно http://localhost:8787.
Пока работает сайт, оставляйте терминал открытым. Ctrl+C останавливает сервер.
При повторном запуске достаточно npm start; после изменения исходников снова выполните npm run build.
Для разработки можно использовать npm run dev.

Для работы с видеозаписями загружайте MP4/H.264 в разделе видеоаналитики.
Модель public/models/yolo/person.onnx включена в репозиторий.
Локально данные сохраняются в эмуляторе Cloudflare D1; перенос исходников не копирует данные смены с опубликованного сайта. Смену можно перенести через экспорт/импорт JSON в интерфейсе.

Камера устройства обычно доступна на localhost. Для подключения с другого устройства нужны HTTPS и доступный с этого устройства адрес; опубликованный сайт уже удовлетворяет этому условию. Команды запуска не публикуют локальную копию.

Файлы обучения и экспериментальные веса находятся в ml/. COCO-изображения скачиваются отдельно по инструкции ml/README.md.
