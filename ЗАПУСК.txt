Запуск TableFlow без VS Code

1. Дважды нажмите на ярлык TableFlow на рабочем столе.
   Или откройте TableFlow.vbs в этой папке двойным щелчком.
2. Дождитесь открытия браузера. Обычно запуск занимает несколько секунд.
3. Сайт откроется по адресу http://localhost:3000/.

Ярлык запускает готовую настольную сборку на Node.js и локальную Ollama
в фоне. VS Code можно закрыть. Среда разработки Cloudflare для ярлыка
больше не используется. После изменения исходников сборка обновляется
автоматически при следующем запуске ярлыка.
Повторное нажатие на ярлык открывает уже работающий сайт.
После перезагрузки компьютера снова нажмите на ярлык.
При временном сбое сервер запускается повторно до трёх раз автоматически.
Ошибки предыдущих попыток сохраняются в журнале.

Данные смены хранятся локально в .data/tableflow-local.sqlite. Таблицы базы
создаются автоматически. Если в старой локальной D1-базе есть сохранённые
смены, они копируются один раз; исходные файлы D1 остаются на месте.

Ярлык использует файлы из текущей папки проекта. Храните эту папку целиком,
включая node_modules, public и .data. Если перенесёте папку, создайте ярлык
для TableFlow.vbs заново. Простое копирование одного HTML-файла не сохраняет
работу базы данных, распознавания и локального помощника.

Для переноса на другой компьютер нужны Node.js 22.13 или новее, зависимости
проекта и Ollama с моделью qwen2.5:3b. Модель находится в папке пользователя
.ollama/models и хранится отдельно от проекта.

Если возникнет ошибка, появится сообщение. Журнал запуска:
.data/tableflow-launch.log
Журнал настольного сервера:
.data/tableflow-dev.log и .data/tableflow-dev-error.log
